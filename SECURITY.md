# Security policy

To report a suspected vulnerability, open the repository’s [Security tab](https://github.com/joebartels/chrome-rehome/security) and choose **Report a vulnerability**. Keep vulnerability reports out of public issues.

Include the affected extension and Chrome versions, the impact, and enough detail to reproduce the issue using synthetic data. Remove credentials, tokens, private URLs, and browsing or session data from any attachments. Use [GitHub Issues](https://github.com/joebartels/chrome-rehome/issues) for ordinary bugs.
