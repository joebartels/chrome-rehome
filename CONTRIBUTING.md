# Contributing

Use [GitHub Issues](https://github.com/joebartels/chrome-rehome/issues) for bugs and proposals. For a bug, include the extension and Chrome versions, what you expected, what happened, and steps using synthetic browsing data where possible. Report vulnerabilities privately using the [security policy](SECURITY.md).

- Start with [development setup](docs/engineering/development.md) and the [engineering principles](docs/engineering/principles.md).
- Keep changes focused. Follow the [testing guide](docs/testing/README.md) and list the checks you ran in the pull request.
- Update affected [documentation](docs/maintaining-docs.md) and follow the [release guidance](docs/engineering/releases.md) for the version bump and package checks.
