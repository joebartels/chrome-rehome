## One minor harness finding

The existing cleanup utility deliberately catches independent failures and preserves the original test error (`tests/browser/external-app-cleanup.ts:16–27`), but its tests do not include the new helper (`tests/unit/external-app-cleanup.test.ts:7–59`). This is test infrastructure resilience, not a handoff/focus defect.

Smallest improvement: include the optional helper release among the independently attempted releases in the existing cleanup utility, and add one portable fault-injection case where helper disposal throws. Assert that context, both servers, launcher and profile cleanup are still attempted and the original test failure remains authoritative. No extra native run is needed to verify this exception path.
