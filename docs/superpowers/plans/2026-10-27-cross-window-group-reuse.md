# Cross-window Group Reuse Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Reuse existing named groups across windows and present foreground incoming tabs without promoting background opens.

**Architecture:** Extend the existing resolver and preserve007a's duplicate-first precedence. Add a narrow presentation intent and native port, execute presentation within journaled placement before closure, and retain read-only recovery.

**Tech Stack:** TypeScript, Chrome MV3 APIs, Vitest, Playwright, Node24.

**Spec:** `docs/superpowers/specs/2026-10-27-cross-window-group-reuse-design.md`.

## Global Constraints

- Chrome120 minimum; Node24; Manifest V3; no dependencies, permissions, configuration schema changes, new controls, or008 features.
- Keep the five-file package contract; preserve incoming identity/history,007a duplicate priority, strict document guards, serialized native settlement, and no URL persistence/replay/timeouts.
- Work in place on the current branch; implementation and independent review are authorized. Complete007b and pause before008.
- Prefix every shell command with `rtk`; use the existing Node24 runtime when the default Node is unsuitable.

## Review Focus

- Multiple same-title remote groups and a current/local group: deterministic preference must not merge or duplicate groups.
- Background tabs and active tabs in unfocused windows: zero activation/focus calls and native surviving selection/focus preservation.
- User switching window/tab during journal/document awaits: no stale focus and no subsequent removal.
- Activation succeeds but focus fails or worker stops: retain incoming tab and duplicates; strict pending recovery blocks replay.
- Real external launch, collapsed destination, and lone source window: preserve incoming history, show foreground destination where authority remains valid, conservatively stop on ambiguous attention.
