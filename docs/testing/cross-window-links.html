ChromeReHome cross-window trial

In window 1, keep one group named Group A. In ChromeReHome settings, save an enabled grouping rule https://example.com/* → Group A. Automatic replacement must already be enabled.

Open this local file in window 2. Before each test, close older tabs at that test URL so duplicate inheritance does not select another location.

  1. Click Foreground test normally. The new tab should join the existing Group A in window 1, become active, and bring window 1 forward.
  2. Return to window 2. Cmd-click Background test on macOS (Ctrl-click on Windows/Linux). The new tab should join Group A while window 2 stays in front and window 1 keeps its previous active tab.

There should still be one Group A. Existing same-name groups are not merged. To check manual organization, move an older duplicate into another group and reopen its exact URL; that duplicate's location should still win.

This page has no scripts and requests nothing until a link is clicked.
